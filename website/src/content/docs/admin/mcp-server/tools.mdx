These are the tools an agent can be offered. It sees only the ones the role of its access key allows, of the plugins that are on.
A change is always two tools: the preview checks everything and changes nothing, the run takes only the preview's handle
and runs after the user agreed.

## Server

| Tool | Kind | What it does |
| --- | --- | --- |
| `oadm_server_info` | Read | The OADM server, who you are, your role and what it allows, the limits of this server and how many devices you see. Call it first. |
| `oadm_server_status` | Read | OADM's own state: OADM PRO, which plugins are on, MCP and the assistant, and the date of the list of Axis vulnerabilities. Read only. |
| `oadm_settings_get` | Read | The server settings OADM shows every user, read only: how it scans, retries, runs tasks and checks clocks. Change them in OADM. |

## Devices

| Tool | Kind | What it does |
| --- | --- | --- |
| `oadm_devices_add_preview` | Preview | Looks for Axis devices with Discovery, in a network range or at IP addresses of the server's own networks or of connected sites. It sends no login and stores nothing. Then call oadm_devices_add_run with the handle: it logs in with the credential list and adds. |
| `oadm_devices_add_run` | Run (changes) | Logs in to the devices of a preview with the credential list and adds those that log in, keeps the waiting addresses, or tries the waiting list. Devices that do not log in are not added. |
| `oadm_devices_credentials_preview` | Preview | Shows which devices would get the login of a stored credential, chosen by its name. Without a name it lists the names; no password is ever sent or shown. |
| `oadm_devices_credentials_run` | Run (changes) | Stores the chosen credential as the login of the devices of a preview and queues their refresh. The devices themselves are not changed. |
| `oadm_devices_get` | Read | One device with its details, as the device details in OADM show them, never its credentials. Take the id from oadm_devices_search. |
| `oadm_devices_optics` | Change | Reads now whether a camera has a remote zoom and focus, and where they stand. |
| `oadm_devices_optics_preview` | Preview | Checks one zoom or focus change against what the camera supports; nothing moves yet. Then call oadm_devices_optics_run with the handle. |
| `oadm_devices_optics_run` | Run (changes) | Moves the camera's zoom or focus as the preview said and answers where they stand afterwards. |
| `oadm_devices_ptz` | Change | Reads now what the PTZ of a camera can do and its presets. |
| `oadm_devices_ptz_preview` | Preview | Checks a move to home, a preset, a zoom or a point against what the camera supports; nothing moves yet. Then call oadm_devices_ptz_run with the handle. |
| `oadm_devices_ptz_run` | Run (changes) | Moves the camera as the preview said. |
| `oadm_devices_refresh_preview` | Preview | Shows which devices OADM would read again. Nothing is changed; then call oadm_devices_refresh_run with the handle. |
| `oadm_devices_refresh_run` | Run (changes) | Queues a full refresh of the devices of a preview. The results show in oadm_devices_search as they arrive. |
| `oadm_devices_remove_preview` | Preview | Shows which devices OADM would stop managing. Nothing is changed; then call oadm_devices_remove_run with the handle. |
| `oadm_devices_remove_run` | Run (changes) | Removes the devices of a preview from OADM, with their stored logins and tags. The devices themselves are not changed. |
| `oadm_devices_rtsp_port_preview` | Preview | Shows the RTSP port OADM uses for the devices of a filter now and after the change; the devices are not changed. Then call oadm_devices_rtsp_port_run with the handle. |
| `oadm_devices_rtsp_port_run` | Run (changes) | Stores the RTSP port of a preview in OADM for its devices (live view and events use it); the devices are not changed. |
| `oadm_devices_search` | Read | Your devices that match a filter, a page at a time with the total and a cursor. Filter by what OADM knows (clock, certificate, chip, CVEs) instead of asking the devices; a filter adds its fields to the rows. |
| `oadm_devices_snapshot` | Read | One JPEG of a camera now, at most 1280 pixels wide, as an image. Take the device id from oadm_devices_search. |
| `oadm_devices_summary` | Read | Counts of your devices by status, model, AXIS OS, site, tag, category, chip, clock, NTP, certificate, vulnerabilities or CVE, and what needs a look (clocks, certificates, CVEs). Call it first: OADM already knows this without asking the devices. |

## Tasks

| Tool | Kind | What it does |
| --- | --- | --- |
| `oadm_task_preview` | Preview | Checks the input and shows what the task would do on the filter's devices; nothing is changed. Show the plan and the skipped reasons to the user, then call oadm_task_run with the handle. |
| `oadm_task_query` | Change | What a task's dialog reads from one device before a change: the users, the network settings, the applications, the time settings, the certificates or the AXIS OS status. Read only. |
| `oadm_task_run` | Run (changes) | Runs the task of a preview on its devices, one task per device. Follow them with oadm_tasks_list and the batch. |
| `oadm_tasks_cancel_preview` | Preview | Shows which tasks of a run or of a list of ids are still waiting or running and would be cancelled; nothing is changed. Show it to the user, then call oadm_tasks_cancel_run with the handle. |
| `oadm_tasks_cancel_run` | Run (changes) | Cancels the tasks of a preview. A running task stops at its next safe point, so a device may be left half done. |
| `oadm_tasks_catalog` | Read | The tasks you may run on the devices of a filter: per task how many can run it, why the others cannot, and its input schema. Call it before oadm_task_preview. |
| `oadm_tasks_delete_all_preview` | Preview | Shows how many tasks the history holds; nothing is deleted. Then call oadm_tasks_delete_all_run with the handle. |
| `oadm_tasks_delete_all_run` | Run (changes) | Cancels every waiting and running task, then deletes the whole task history. |
| `oadm_tasks_delete_preview` | Preview | Shows which tasks of a run or of a list of ids would leave the task history; nothing is deleted. Then call oadm_tasks_delete_run with the handle. |
| `oadm_tasks_delete_run` | Run (changes) | Deletes the tasks of a preview from the history with their steps and logs. A waiting or running task is cancelled first. |
| `oadm_tasks_get` | Read | One task with its steps and its log (the newest 200 lines). Take the id from oadm_tasks_list. |
| `oadm_tasks_list` | Read | Tasks of your devices from OADM's task history, the newest first, with the counts per state first. Pass batch to follow the tasks of one run; next_cursor for the next page. |
| `oadm_tasks_summary` | Read | OADM's task history of your devices summed up: counts per state and groups by result, task, plugin, owner, device or day, the largest first. Pass status Failed to group the failures by their error. |
